# VoiceKhata

**A voice-first digital ledger for small vendors, designed for Gemma 4.**

VoiceKhata aims to help shopkeepers record credit sales, payments, and shop expenses without complicated bookkeeping. This repository currently contains the first MVP: a simple Streamlit ledger with explicit confirmation before saving and deterministic SQLite balance calculations.

## Current MVP

- Record a credit sale, payment received, or shop expense.
- Require the user to confirm details before saving.
- Store transactions locally in SQLite.
- Calculate customer balances in Python.
- Keep shop expenses separate from customer balances.
- Show customer balances and recent transactions.

**Note:** Voice capture and Gemma 4 transaction extraction are planned next; they are not yet connected in this first milestone.

## Run locally

Requires Python 3.10 or newer.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

The app creates `voicekhata.db` locally when it first runs. That database is ignored by Git.

## Run tests

```bash
pytest -q
```

## Transaction rules

- **Credit sale:** increases the customer's amount due.
- **Payment received:** reduces the customer's amount due.
- **Shop expense:** recorded in the ledger but excluded from customer balances.
- Only confirmed transactions should be saved.
- Balance arithmetic is handled by Python, not generated by an AI model.
